To deploy your application, mount your SPA build directory to /app/ when running this container. For example, using Docker:

docker run \
  -p 8080:8080 \
  -v $(pwd):/app \
  ghcr.io/pyck-ai/baseimages/nginx:latest

If you need to customize the NGINX configuration, you have the following options:

  • You can extend the default configuration by adding your own files in the /etc/nginx/conf.d/ directory.
  • You can override the default configuration by replacing the default /etc/nginx/conf.d/default.conf file.
  • You can override the main /etc/nginx/nginx.conf file.
It is strongly recommended you do not override the main configuration file, unless you absolutely have to. This is to ensure that essential settings are preserved and automatic updates are applied via the base image.
